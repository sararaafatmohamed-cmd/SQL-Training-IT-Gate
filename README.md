# SQL Training – IT Gate

SQL Server training completed during IT Gate in July 2025.

This repository contains practical SQL exercises and database projects completed during the training, covering SQL fundamentals and relational database concepts.

## Topics Covered

- Creating and modifying databases and tables
- Primary Keys and Foreign Keys
- Table relationships and relational database design
- Inserting, retrieving, and modifying data
- Filtering and sorting data
- Aliases and DISTINCT
- LIKE, BETWEEN, IN, AND, OR, and NOT
- Subqueries
- Aggregate functions: COUNT, SUM, AVG, MIN, and MAX
- GROUP BY
- INNER, LEFT, RIGHT, and CROSS JOIN
- Many-to-many and self-referencing relationships
- DELETE and TRUNCATE

## Practice Databases

- Company Database
- IT Database
- Library Database
- Cinema System
- Electronics Shop Database
